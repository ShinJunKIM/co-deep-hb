# 사전등록 초안 — 0.54 µm 탄성 과대예측, 라운드 X-L (라이너 링 효과; 진단) — 런 전에 커밋할 것

**지위.** 탐색(exploratory). 0.54 µm 측정값은 이미 본 데이터이므로 held-out이 아니다. 목적은 "라이너 링(둘레/면적 ∝ 1/w)이 0.54 µm 오차 중 얼마를 설명하는가"를 숫자로 고정하는 것이며, 검증 판정(NOT VALIDATED)은 바꾸지 않는다. 라이너 두께 15/25 nm는 문헌 근거가 없는 **진단값**이다(채택값 6 nm, Tsau 2022).

## 1. 가설
H-A: imec 0.54 µm 패드의 배리어/시드 적층이 모델의 6 nm보다 두껍거나 유효 강성이 커서, 링이 Cu 기둥의 수직 열변형을 둘레/면적에 비례해 줄인다. 해석적 추정(복합 기둥 α_eff): t 15 nm → −10 %, 25 nm → −15 %; 반경 구속 포함 −20 % 안팎. 1.26 µm 이상에서는 −3 % 이하.

## 2. 런 (동일 모델, 라이너 두께만 변경; 2D 축대칭, imec 채택 SiCN E 120 GPa·α 2.0 ppm/K, 배열 셀 2.26 w, Hill 등방 Cu, 접합 측벽, 25→100→200→300→400 °C)

```python
# src/stage2/stage2_x_runs.py 와 같은 _run 시그니처; IM = adopted imec dict(E_d=120000.0, a_d=2.0e-6)
_run("X30", "XL", "imec", 0.54, 0.6, "XL liner 15 nm, 0.54 um array cell", cell_factor=2.26, t_liner=0.015, **IM)
_run("X31", "XL", "imec", 0.54, 0.6, "XL liner 25 nm, 0.54 um array cell", cell_factor=2.26, t_liner=0.025, **IM)
_run("X32", "XL", "imec", 1.80, 0.6, "XL liner 25 nm, 1.80 um array cell (control)", cell_factor=2.26, t_liner=0.025, **IM)
_run("X33", "XL", "imec", 1.26, 0.6, "XL liner 25 nm, 1.26 um array cell (control)", cell_factor=2.26, t_liner=0.025, **IM)
_run("X34", "XL", "imec", 0.54, 0.6, "XL liner 25 nm + pitch 1.7 w (2D 1.92 w), 0.54 um", cell_factor=1.92, t_liner=0.025, **IM)
```
기준값(라이너 6 nm, 배열 셀): S112 0.54 µm du_c50 2.039 nm; 1.80 µm 4.99; 1.26 µm 4.04 (400 °C). 측정: 1.40 / 5.40 / 5.00.
후처리(런 없음): S112·1.26·1.80·3.06 µm 배열 런의 `top_disp.txt`를 `baseline.u_history`로 afm_field = 2 w, 3 w, 4 w로 재평가해 네 크기의 오차를 표로 만든다(B′, 기준면 지역화 가설 닫기용).

## 4. 판정 규칙
- **R1 (크기 선택성):** X31/S112 − 1 ≤ −0.10 이고 X32/4.99 − 1 ≥ −0.05 이면 "라이너 링은 크기 선택적 인자"로 기록.
- **R2 (설명 몫):** 0.54 µm 오차 중 라이너가 설명하는 몫 = (2.039 − X31)/(2.039 − 1.40). 예측 0.35–0.55. 몫 ≥ 0.8이면 "라이너 두께가 0.54 µm 오차의 주요 원인 후보(문헌 두께 확인 필요)"로, 0.3–0.8이면 "부분 설명", < 0.3이면 "기각".
- **R3 (조합):** X34가 측정 ±25 %(1.05–1.75 nm) 안이면 "라이너 25 nm + 피치 1.7 w가 측정과 일치하는 조합"으로 기록하되, 두 값 모두 문헌 근거가 없으므로 모델 채택값은 바꾸지 않는다.
- B′: 네 크기 모두 ±25 % 안에 드는 k가 있으면 "스캔 크기 ∝ 패드 크기 가설 생존", 없으면 닫음(예측: 닫음).

## 5. 보고 방식
결과는 탐색 로그와 보고서 §12 표에 한 줄씩, 한계 절의 0.54 µm 항목에 "라이너 두께가 설명하는 몫 ○ %(진단, 문헌 두께 미확인)"로 적는다. 검증 판정·채택 파라미터·예측 창은 바꾸지 않는다.
