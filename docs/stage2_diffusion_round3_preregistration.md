# Stage 2 · 확산 항 라운드 3 — 미사용 데이터(DM2023)로의 held-out 시험 (사전등록; DM2023 값을 읽기 전에 커밋)

**작성 2026-10-16.** §1–§4는 DM2023 Fig. 7·9를 디지타이징하기 전에 커밋한다. 근거 분석: `docs/agents/diffusion_round3_prereg_draft.md`, `docs/agents/master_curve.md`(둘 다 DM2026을 본 뒤의 탐색). 이 라운드의 held-out은 **DM2023 Fig. 7·9만**이다(한 번도 읽지 않음).

## 1. 탐색에서 결정한 것 (왜 이 형태인가)

- DM2026 17점에서 실패는 전부 200 °C·큰 패드·자가 어닐 Cu의 과소예측이었다. 탐색 결과: (a) 활성화에너지는 Butrymowicz 집계의 저온 전계방출 값 **13 kcal/mol**(Melmed, 50–171 °C; p.9)이 200–350 °C 데이터와 맞고(마스터 커브 적합 Q_eff 13.4, 68 % CI 12.5–14.8), 20.7(Bonzel–Gjostein 계열)은 너무 가파르다; (b) 동역학 형태는 Mullins 스케일링(특성 길이 ∝ (Bt)^{1/4})에 따른 stretched exponential β = 1/4이 포화 비(D250 1.10 vs 측정 1.13 ± 0.11)와 200 °C 크기 경향을 함께 맞춘다; (c) Cu 이력(도금 후 어닐 vs 자가 어닐)은 진폭이 아니라 동역학(τ₀ 3배 차이)에 들어간다.
- 그러나 (a)–(c)는 모두 DM2026을 본 뒤의 결론이므로 DM2026으로는 더 이상 검증할 수 없다. 그래서 **모델 형태와 상수를 지금 고정**하고 DM2023으로 시험한다.

## 2. 모델 (고정; 자유 파라미터 없음 — 모든 값은 DM2026 보정 또는 문헌)

h_d = s_ox · a · D_amp · f(ω) · g(t/τ), g = 1 − exp[−(t/τ)^β], τ = τ₀,hist · (D_kin/200 nm)^n · exp[Q/R (1/T − 1/623.15 K)]
- a = 0.0546 nm/nm(θ_eff 114.8°; 마스터 커브 PPA 적합), f(ω) 라운드 2 형태(ω_c 5°, Δω 19.5°; 중앙값 비교에서는 f의 중앙값 사용 → 분포 중앙값은 MC로 계산), **β = 1/4**(주), Q = **13.4 kcal/mol**, n = 3.7(DM2024; 마스터 커브의 n 0.2는 두 크기뿐이라 식별 안 됨 → 문헌값 유지), τ₀,PPA = 0.16 h·(보정 시 β = 1 기준이었으므로 β = 1/4 재보정값: `src/agents/diffusion_round3.py`의 C3 설정에서 400 nm 피치·350 °C 1 h 점으로 다시 맞춘 값을 커밋 직전에 계산해 아래 §5에 기록), τ₀,self = τ₀,PPA/3.
- s_ox = 1(DM2023 Fig. 7·9는 표준 세정; Fig. 10의 산화 플라즈마 분할은 별도 보고).

## 3. Held-out 데이터와 기하 규칙 (값을 읽기 전 고정)

- DM2023(refs/pdf/De Messemaeker 2023 ECTC.pdf) Fig. 7: cavity/pad 300/600 nm, 230·350 °C, 5 min·2 h 등 시간 분할; Fig. 9: 200/400, 200/500, 300/600 조합(피치 0.8–1.2 µm). 분포 그림이면 중앙값(50 % 교차)과 IQR을 읽는다. 디지타이징 방법·오차 기록은 Phase 3와 같다.
- **기하 규칙:** 불균등 패드(cavity/pad ≤ 0.5)에서는 bulge가 cavity 면적에 갇혀 높이로 환산되므로 **진폭의 D_amp = cavity 지름**, 동역학의 **D_kin = 패드 지름**(원자가 이동하는 표면은 바닥 패드). 이 규칙이 틀리면 전부 틀릴 수 있다 — 그것이 이 시험의 위험이고, 실패 시 "기하 규칙" 개정 1회를 허용한다(이유 선커밋).
- 제외: 미세결정 Cu(있다면), 산화 플라즈마 분할(Fig. 10), 300 °C 이상·2 h 포화점은 진폭 규칙만 시험하는 점으로 표기.

## 4. 통과 기준 (Phase 3와 동일 형태)

- 점별: |예측 중앙값 − 측정 중앙값| ≤ max(1.5 nm, 25 %, 디지타이징 오차). **VALIDATED(라운드 3)** = held-out 점의 ≥ 80 % 통과 **그리고** T 경향(230 → 350 °C 상승) **그리고** 시간 경향(350 °C 5 min → 2 h: 측정이 "5 min에 이미 형성"이면 예측 비 ≤ 1.3이어야 함).
- 사전 예측: 350 °C 점은 포화라 진폭·기하 규칙만 맞으면 통과; 230 °C 점은 β = 1/4·Q 13.4가 지수형·Q 20.7보다 훨씬 큰 값을 주므로 **통과 가능성 높음**, 다만 cavity/pad ≤ 0.5의 기하 환산이 2배 이상 틀리면 실패. 정직한 기대: 60–80 %.
- 개정 1회(기하 규칙만). 결과는 통과·실패 모두 보고하고, 공정창은 라운드 3가 VALIDATED일 때만 이 모델로 재계산한다(아니면 현재 창 유지 + Q·β 불확실 구간 확대).

## 5. 커밋 직전 고정값 (디지타이징 전)

- τ₀는 **보정하지 않는다**(라운드 2·마스터 커브와 달리; 350 °C 1 h 점이 포화에 가까워 β = 1/4에서 τ₀가 식별되지 않음을 확인 — 보정하면 τ₀ ≈ 20 s로 밀려 200 °C를 과대예측). τ₀,PPA = **60 s**(사전등록 중앙값, DM2023·Tsau), τ₀,self = 20 s(마스터 커브의 이력 비 1/3).
- 400 nm 피치·350 °C 1 h에서 g = 0.896 → a = 12.96/(250·g) = **0.0579 nm/nm**(θ_eff 116.3°). 중앙값 비교의 f 중앙값은 1.0(ω_c + Δω = 24.5° 안의 패드가 36 %)이므로 중앙값 예측은 a·D_amp·g, 분포는 MC.
- 이 설정(C3: β 1/4, Q 13.4, τ₀ 60 s)은 DM2026(이미 본 데이터)에서 중앙값 13/17·IQR 17/17이었고, 실패는 PPA-Cu 200 °C 2 h/4 h(과대)였다 — 즉 라운드 3에서 230 °C PPA 점이 있으면 과대예측으로 실패할 수 있다. 그대로 간다.
