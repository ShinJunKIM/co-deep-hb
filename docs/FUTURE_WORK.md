# 후속 연구 목록 (2026-10-16 개정, 제출본 v5 이후)

v4.3 목록(9개)을 다시 정리했다. 기준은 세 가지다. 지금 손으로 할 수 있는가, 하면 300 nm 접합 측벽 결론이 바뀌는가, 순서가 맞는가.

## A. 지금 할 수 있는 것 (문헌 조사, 새 측정 없음)

| # | 과제 | 왜 필요한가 | 방법 |
|---|---|---|---|
| A1 | 확산 방위 함수 f(ω) 문헌 데이터 | 남은 불확실성 중 꼬리 모양이 경계를 15–16 °C(시간 ×1.9) 옮긴다. 판독 범위 아래(누적 0.5 % 미만) 꼬리를 줄일 수 있는 유일한 경로 | 결정립 방위별 bulge-out/표면 이동 측정(EBSD + AFM/TEM) 논문 조사. 찾으면 f(ω) 변형 6종 중 어긋나는 것을 사전등록 기준으로 제외 |
| A2 | 250 °C 이하 bulge-out 시간 변화 데이터 | 활성화에너지 Q의 영향이 저온·장시간일수록 커진다(시간 배수 320 °C ×1.4 → 220 °C ×4.7). 모든 조합 2시간 경계(248 °C)가 데이터 하한(250 °C) 바로 위에 있다 | 같은 크기 패드, 200–250 °C 어닐 시간별 돌출 데이터 문헌 조사. 없으면 '250 °C 미만 레시피는 주장하지 않는다'로 끝낸다 |

A2를 논문에서 굳이 설명할 필요는 없다. 본문은 이미 250 °C 미만을 '데이터 밖, 모델 보수적'으로 표시하고 레시피를 주장하지 않는다. 한계 문장 한 줄이면 충분하다.

## B. 측정이 있어야 하는 것 (이 연구 안에서는 해결 불가, 한계로만 기술)

| # | 과제 | 막는 이유 |
|---|---|---|
| B1 | 정확히 <111>인 패드의 bulge-out f(0) | 최악 방위 결론(0이면 어떤 어닐로도 최악 쌍 불충분)을 이 한 값이 정하지만 실측이 필요하다 |
| B2 | 300 nm 돌출 실측 | 300 nm 결과는 예측이며, 검증하려면 측정이 필요하다 |
| B3 | 0.54 µm 탄성 오차 원인 | imec 원 데이터(Okudur 2017)의 측정 정의가 필요하다 |
| B4 | 체인 수율 검증 | 같은 크기 sub-µm 데이지체인 수율 공개 데이터가 필요하다 |

## C. 하지 않는 것 (결론을 바꾸지 않거나 순서가 틀림)

| 과제 | 이유 |
|---|---|
| 미끄럼 계면 접촉 FEM 공정창 | 제출본 범위가 접합 측벽이다(v5). 접합에서는 높이합 판정과 접촉 FEM이 4/4 일치해 결론이 바뀌지 않는다 |
| 방위 대리모델의 다른 크기·적층 확장 | 300 nm 대리모델은 154런과 미사용 20방향 검증으로 이미 끝났다(최대 오차 0.46 %). 300 nm의 남은 불확실성은 탄성이 아니라 확산 쪽이므로, 다른 크기로 넓히기 전에 A1·A2가 먼저다 |
| 불균등 패드(상·하 크기 다름) | 확산 항이 같은 크기 패드에서만 성립한다(DM2023 불균등 0/7). 범위 밖으로 명시 |
| 표면확산 형상 진화 FEM, 300 nm 단결정 소성(R61), ST/Leti 계면 정량 불일치, 오버레이·크리프 | 장기 과제이거나 다른 PC 작업이거나 범위 밖. 제출본 결론과 무관 |
