# Stage 2 V&V 계획 — 고정 파라미터와 통과 규칙 (held-out 비교 전 커밋)

ASME V&V 10-2019 순서: 검증(verification) → 보정(calibration) → 검증(validation) → 예측. 이 문서는 보정이 끝난 시점의 **고정값**과 held-out 통과 규칙을 기록한다. 이 커밋 이후 보정 파라미터는 바꾸지 않는다. 검증 실패 시 한 번의 문서화된 개정만 허용(이유를 먼저 커밋).
