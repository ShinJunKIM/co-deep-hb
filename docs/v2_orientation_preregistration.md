# v2 · 결정방위 정보를 유지한 탄성 돌출 — 300 nm, 접합/미끄럼 (사전등록, 런 전 커밋; 2026-10-16)

**지위.** 10/19 제출본과 분리된 후속 연구(브랜치 `v2-orientation`). 이 문서의 규칙은 VB/VS 런 결과를 보기 전에 커밋한다.

## 1. 질문
1. Cu 패드 수직축의 방향 2자유도(정렬 hkl → (x, y) = (k/h, l/h), 1 ≥ x ≥ y ≥ 0)만으로 탄성 돌출을 기술할 수 있는가? 면내 회전각은 필요한가?
2. E_z 하나로 축약하면 정보를 잃는가(같은 E_z, 다른 방향)?
3. 저차 다항 회귀 응답표면(대리모델)이 학습에 쓰지 않은 방향에서 접촉 판정에 충분한 정확도를 주는가?
4. 접합 측벽과 미끄럼 측벽에서 방위 효과의 크기는 어떻게 다른가?

## 2. 구현 확인 (코드)
- 이방성 Cu: `stage1_pipeline.rotated_D(hkl, angle)`가 입방 탄성텐서(168.4/121.4/75.4 GPa)를 4차 텐서로 회전해 전역 좌표 21개 상수(TB,ANEL)로 넣는다. 회전행렬의 z행 = 정렬 hkl 방향, x행 = 결정 [001]의 수직면 투영, angle = z축 둘레 면내 회전. `baseline.material_lines`가 이제 hkl 튜플과 `cu_angle`을 받는다(기존 덱 해시 불변 확인).
- 셀: 3D 정사각 주기 셀(셀 = 피치 2.0 w), O-grid 원형 패드, 전 셀 해석(1/4·1/8 대칭 미사용). 정사각 배열은 4회 대칭이지만 결정의 면내 방향과 정렬되지 않으므로 대칭 축소를 쓰지 않는다 — 면내 회전 영향은 R 세트로 직접 측정한다.
- 측벽: 접합 = 절점 공유. 미끄럼 = Cu 측벽 절점을 복제해 법선 변위만 라이너 절점과 묶음(CE; 접선 자유, 분리 없음). 라이너–유전체는 항상 접합, Cu 바닥 림은 공유. 캡 없음(imec 비접합 웨이퍼 in-situ 조건).
- 관측량: k = du_c50/(T − 25) [nm/K](중앙 50 % 면적 평균 − AFM 시야 유전체 평균). 선형 탄성·물성 일정이므로 u ∝ ΔT(편차를 기록해 확인).

## 3. 방향 표본
- **T(학습, 45):** x, y = i/8, j/8 (0 ≤ j ≤ i ≤ 8) — [100], [110], [111] 꼭짓점·변·내부 격자.
- **H(검증, 20; 학습에 쓰지 않음):** 내부 무작위 8(시드 20261016), [111] 근방 4, **같은 E_z 쌍 4개(8점)**: E_z = 73.9/82.9/94.3/109.4 GPa에서 [100]–[110] 변(y = 0)과 [100]–[111] 변(x = y) 위의 두 방향.
- **R(면내 회전, 12):** (0,0), (0.5,0), (1,0), (0.5,0.25), (1,0.5), (1,1) × 22.5°, 45°(0°는 T에 있음).
- 계면 2종 × 77 = **154 런**. 예상 시간: 기존 같은 셀·같은 노드 수 3D 런(S68 25 s, S70 27 s, S77 25 s) 기준 접합 ≈ 25–30 s; 미끄럼(노드 20 662, CE 1 064)은 실측 없음 → 30–60 s 추정. 합계 ≈ 1.2–2 h. 실측은 결과 절에.

## 4. 판정 규칙 (사전 고정)
- **R-O1 (E_z 축약):** 같은 E_z 쌍의 k 상대 차이가 모두 ≤ 2 % **그리고** ≤ 학습 세트 방위 폭(max−min)의 25 %이면 "E_z 축약으로 잃는 정보 없음". 아니면 "E_z 축약 부족 → 2자유도 유지".
- **R-O2 (면내 회전):** 각 방향의 0/22.5/45° k 범위가 ≤ 2 % **그리고** ≤ 방위 폭의 25 %이면 "방향 2자유도로 충분". 아니면 각도를 입력에 포함.
- **R-O3 (대리모델):** 선택 순서 고정 — 2차 다항(6계수) → 실패 시 3차(10계수) → 실패 시 구간선형 보간. 합격 = H 20점에서 최대 |오차| ≤ 평균 k의 5 % **그리고** u(400 °C)로 환산해 패드당 ≤ 0.1 nm(접촉 여유의 기준 눈금). 학습점 적합도는 판정에 쓰지 않는다.
- **R-O4 (취약 방향):** 대리모델의 삼각형 전체 최소 k와 그 위치가, 관측된 65점 중 최소 k와 2 % 안이고 같은 꼭짓점/영역이면 "취약 방향 재현".
- **R-O5 (안정성):** T+H 65점으로 다시 적합해도 최소 k 변화 ≤ 1 %이고 300 nm 공정창(주 설정)의 셀이 바뀌지 않으면 "표본 충분(이 기준에서)". 아니면 R 결과·오차가 큰 곳에 10방향 추가(다음 사전등록).
- **R-O6 (계면별 차이, 보고):** 학습 세트 방위 폭. 사전 예측: 접합 4–7 %(기존 S68–S78: 5 %), 미끄럼 15–45 %(2D/고립 셀 이력 기반 추정, 근거 약함).
- **R-O7 (공정창 영향, 보고):** E_z 적합 대신 대리모델로 탄성 항을 계산했을 때 공정창·최악 방위 여유·허용 recess가 바뀌는 셀 수와 nm.
