## B. 구속 계수 대리식 보간 시험 (X-S): C = c₀/[1 + a·(E_d/E_Cu)·(h/w)^1.5]

근거: 167개 FEM 런과 19개 실측이 C = u/[(α_Cu − α_Si)·ΔT·h] vs h/w 한 곡선 위에 놓이고(배열 셀 적합 c₀ 1.95, a 2.2, 상대 rms 15 %), 0.54 µm 실측만 이탈한다. 대리식이 적합에 쓰지 않은 기하를 ±20 % 안에서 맞추면 탄성 항을 임의 크기·유전체에 대해 대리식으로 쓸 수 있다(공정창 계산의 일반화).

| ID | 조건 | 사전 예측 C | (u(400 °C) 환산) |
|---|---|---|---|
| X35 | imec, 배열 2.26 w, w 0.90 / h 0.60 | 0.92 | 2.88 nm |
| X36 | imec, 배열 2.26 w, w 0.40 / h 0.60 | 0.41 | 1.28 nm |
| X37 | imec, 배열 2.26 w, w 0.54 / h 0.30 | 1.05 | 1.64 nm |
| X38 | NYCU 채택 적층(SiO2 59 GPa·1.0 ppm, Ta 50 nm, 테이퍼 18°), 고립 12 w, w 1.0 / h 0.6, 200 °C | 1.38 | 2.12 nm(200 °C, ΔT 175) |

규칙: 네 런의 FEM C가 모두 예측 ±20 % 안 → **대리식 사용 가능**(탄성 항의 일반화 근거). 하나라도 밖이면 "대리식은 적합 범위 안에서만". 부수: X36(h/w 1.5) vs X37(0.56)이 "같은 폭에서 h만 줄이면 C 0.65 → 1.05"를 보이면 0.54 µm 결손이 모델 안의 h/w 함수가 아님을 재확인(측정 이탈 = 고립 이상점).

환산: u = C·(α_Cu − α_Si)·ΔT·h, α_Cu − α_Si = 13.9 ppm/K, ΔT = 375 K(400 °C) 또는 175 K(200 °C).
