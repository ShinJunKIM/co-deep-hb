## 2. 두 경계 — 0.7 µm는 "탄성 접촉 한계"다

- **탄성 접촉 한계:** u_t + u_b = r_t + r_b. 현재 ≈ 0.7 µm는 이것이다. 산출: recess 합 5 nm 고정, 400 °C 탄성 돌출(imec 실측 0.54/1.26/1.80/3.06 µm = 1.40/5.00/5.40/7.85 nm)의 2u가 5 nm를 넘는 폭을 log 보간 → 실측 0.70 µm, 모델 0.66(b = 1)–1.06 µm(b = 0.69). recess 3/4/5/6/8/10 nm → 실측 0.55/0.62/0.70/0.79/1.00/1.26 µm (`paper_results.json` transition_vs_recess). 측정점 두 개(0.54, 1.26 µm) 사이 보간이다.
- **기여도 역전:** h_d,t + h_d,b = u_t + u_b. 아직 계산된 적 없다. → {CROSSOVER} (어닐 조건별, D > 300 nm은 확산 진폭 외삽). 확산 진폭 ∝ D(포화)와 τ ∝ D^3.7(동역학)이 경쟁하므로 고정 어닐에서 큰 패드는 확산이 미완료라 역전 폭이 유한하다.
- 0.7 µm를 "기구 전환"이라 부른 곳(모두 1.2 표 #1–#7로 수정):
  - `docs/paper/ieie2026f_plan_and_draft_ko.md` L13, L16, L27, L52, L81, L92(및 §1 기여 문장).
  - `docs/paper/claude_science_prompt_ko.md` L18("기구 전환 크기"), L30("접촉 기구 전환 폭"), L48("mechanism_transition") → "탄성 접촉 한계".
  - `docs/paper/ieie2026f_proceedings_final.docx` 단락 4, 23, 27, 43, 60; `ieie2026f_blind_final.docx` 단락 3, 10, 15, 30, 43.
  - `results/stage2/paper_results.json` 키 `mechanism_transition`, 그림 `results/figures/s2_mechanism_transition.png` 제목 "mechanism transition: elastic closes the recess only above ≈ 0.7 µm" → 파일명은 두되 그림 제목을 "elastic contact limit"으로.
- 보고서 §15·`stage2_paper_argument_ko.md`에는 "전환" 표현이 남아 있지 않다(검색 결과 없음).

- 지지: 같은 회사·같은 Cu/SiO2 Ta/TaN 공정 계열(○, 공저 관계와 소속에서 추론), 같은 400 °C 열이력.
- 반대·불확실: Ayoub는 비접합 + SiN 캡, Lhostis는 접합(캡 없음, 유전체 접합면). "캡 비하중"은 Ayoub에만 의미가 있고 Lhostis에는 해당 계면이 없다. 측벽(Cu–라이너) 계면만이 두 관측의 공통 변수다. 라이너 두께는 두 원문 모두 미기재. Lhostis의 dishing d0 미기재.
- 결론: **공통으로 시험할 수 있는 것은 "Cu–라이너 측벽 미끄럼" 하나**다. Ayoub 쪽은 추가로 캡 조건이 걸려 있어, 두 관측이 같은 계면 상태를 가리킨다고 하려면 측벽 미끄럼 설정 하나로 (i) Lhostis 폭·두께, (ii) Ayoub 300 nm·3 µm를 모두 평가해야 하며, Ayoub는 캡 두 경우(접합/제거)를 함께 보고해야 한다.

## 5. 동일 모델 평가표

규칙: **어떤 시나리오도 그 시나리오의 관련 관측 전부를 한 설정으로 평가하기 전에는 "검증"이라 하지 않는다.** 한 관측에 접합, 다른 관측에 미끄럼을 골라 쓰지 않는다.

| 관측 | 접합 | 측벽 미끄럼 + 캡 접합 | 측벽 미끄럼 + 캡 없음 |
|---|---|---|---|
| Ayoub 300 nm ε′zz 부호 | FAIL (S61/S62 부호 반대) | FAIL (SD10/SD3 ε′zz(30) 비 −0.78/−0.82) | PASS (SD10N/SD3N +0.58/+0.91; S63 패드 3 −8…−11 %) |
| Ayoub 300 nm 기울기 크기(V5: 부호 + 25 %) | 크기 0.5 %, 부호 FAIL | FAIL (−0.81/−0.85) | 패드 3 PASS (0.94), 패드 10 FAIL (0.60); 방위 비 0.41 vs 측정 0.64 |
| Ayoub 3 µm 부호 | PASS (SC1–SC4) | **미계산** → SC6 | **미계산** → SC5 |
| Lhostis 폭 효과 (V(0.11) ≥ V(0.36)+0.10) | PASS (0.62 vs 0.10, E64/E55) | 해당 없음(접합 시료에 캡 없음) | **미계산** → E70 (기준 V(0.36, 0.22, 2, 미끄럼) = 0.15, E67) |
| Lhostis 두께 효과 | FAIL (라운드 1 A_c, 라운드 2 V: 0.08/0.10, 0.51/0.62) | 해당 없음 | PASS (V 0.000/0.15 r0 2, 0.24/0.54 r0 4; E66–E69) — 단, 기록을 본 뒤 설계 |
| imec/NYCU 돌출 | PASS(1 µm, 1.80, 1.26 ≤ 200 °C), 0.54 FAIL | 해당 없음(캡 없는 시료) | FAIL (V4: 3.66 vs 2.1, 4.84 vs 1.40) |

빈 칸 실행 조건:
- **E70**: `stage2_lhostis_r2._mk("E70", 0.11, 0.22, 2.0, …, side="sliding")` — SiO2 59 GPa·1.0 ppm/K, Ta 13 nm, 400 °C, 셀 2.26 w, Okoro 벌크. 판정: 규칙 A와 같은 식, 기준은 E67(0.15). (부모가 이미 등록함.)
- **SC5 / SC6**: `stage2_wide.py` SC4(Hill, WB 메시, 6 µm 피치, T_sf 200 °C, Ta 13 nm, SiO2 59/1.0)에 `sliding=True` + `cap=False`(SC5) / `cap=True`(SC6). WB 메시(74,925 절점) 사용 — WA(120,787)에 측벽 복제가 붙으면 Student 한도(128k)에 근접. 판정: 30 °C ε′zz 부호(Ayoub 3 µm 음수)와 |ε′zz| ≥ 1e-4.
- 판정 묶음: 미끄럼 + 캡 없음 시나리오가 SC5 음수 **그리고** E70 통과 **그리고** 기존 SD10N/SD3N·E66–E69 결과를 모두 만족해야 "ST/Leti 관측 전부와 일관"이라 쓸 수 있다. imec/NYCU에서는 같은 시나리오가 FAIL이므로 공정별 다른 계면 입력이라는 주장이 된다(가설; 계면 직접 관측 없음).
