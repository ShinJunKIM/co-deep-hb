# v2 · 높이합 접촉 판정 vs 접촉 FEM — 미끄럼 계면 경계 조건 (사전등록, 런 전 커밋; 2026-10-16)

## 목적
공정창은 "패드 중심 높이합 ≥ recess 합"(높이합 판정)으로 계산했다. 이 판정이 소성·림 형상을 포함한 접촉 FEM(2D 축대칭, Cu–Cu 마찰 접촉 μ 0.3, Okoro 벌크 소성, 구면 캡 dishing)과 경계 근처에서 같은 결론을 내는지 시험한다. 미끄럼 계면에서는 300 nm 패드가 탄성만으로 닫히는 영역이 생기므로(v2 방위 연구 §6), 확산 없이 접촉 FEM으로 직접 확인할 수 있다.

## 기존 기록(접합, 탐색 — 이미 본 데이터)
E25–E28(0.30 µm, 350 °C, imec SiCN, 접합): 중심 높이합 2u_ctr ≈ 2.66 nm(S67 Hill du_ctr 1.533 nm @400 °C를 350 °C로 선형 환산)와 2r 비교 → r 1 닫힘 / r 2·3·4 미닫힘 예측. 접촉 FEM 중심 공극 분율 V = 0.00 / 0.06 / 0.32 / 0.47 → V ≤ 0.05를 "닫힘"으로 보면 4/4 일치(r 2는 경계).

## 판정 규칙
- 접촉 FEM "닫힘" = 400 °C가 아니라 해당 T 하중단계에서 중심 공극 분율 V = (r_in/A)² ≤ 0.05.
- 4런 중 ≥ 3개에서 높이합 예측과 일치하면 "미끄럼 계면에서도 높이합 판정은 접촉 FEM과 일관(경계 ±1 nm 수준)". 2개 이하면 "높이합 판정은 미끄럼 계면에서 접촉 FEM과 어긋남 — 공정창은 조건부".
- 사전 예상: 소성 압출이 닫힘을 돕기 때문에 E72·E74가 예측보다 잘 닫힐 수 있다(불일치 위험은 미닫힘 예측 쪽).
- 개정 없음.

**판정: 2/4 → 높이합 판정은 미끄럼 계면에서 접촉 FEM과 어긋난다(사전 규칙).** 어긋남은 사전 예상과 반대 방향이다(소성이 닫힘을 돕는 대신, 높이합이 닫힘을 과대예측).
**기구(해석).** 접합 계면에서는 측벽이 Cu를 붙잡아 표면이 돔 모양으로 솟으므로(중심 > 가장자리) 중심 높이가 닫힘을 정하고, 기존 E25–E28에서 높이합 판정이 4/4 맞았다. 미끄럼 계면에서는 Cu 기둥이 플러그처럼 통째로 올라가 dishing 모양(가장자리 0, 중심 −r)이 그대로 유지된다. 그래서 가장자리 고리가 먼저 닿아 압력(440–480 MPa)을 받으며 더 오르지 못하고, 중심 공극이 남는다. 즉 "중심 높이합 ≥ recess 합"은 돔형 상승(접합)에서만 닫힘의 대리 지표이며, 플러그형 상승(미끄럼)에서는 가장자리 접촉만 보장한다.
**함의.** v2 방위 연구 §6의 "미끄럼 계면에서는 300 °C 이상 탄성만으로 닫힘"은 **가장자리 접촉** 기준으로 정정한다; 중심까지 닫히려면 확산(bulge-out, 중심을 높임)이 필요하다. 미끄럼 시나리오의 공정창은 높이합 판정으로는 낙관적이다.
