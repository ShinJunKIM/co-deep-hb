# 축소안 v5 — 주장 범위를 "측벽 접합 공정"으로 한정 (원고 v4.3 기준)

작성 2026-10-16. 대상: `docs/paper/ieie2026f_plan_and_draft_ko.md` (v4.4, 1bb4740 기준). **원고에 적용됨(v5).**

## 0. 원칙

1. **범위 조건.** 모든 정량 주장은 Cu 측벽이 라이너에 접합된 공정(imec·NYCU형, 돌출 실측이 접합을 요구)에 한정한다. 이 범위에서는 높이합 판정이 접촉 FEM의 닫힘과 일치하므로(4/4, 기존 기록 재분석) "접촉 = 계면 닫힘"으로 쓰고 연결 단계는 따로 다루지 않는다.
2. **기여 3 → 2.** 기여 ② "계면 조건을 하나의 설정으로 평가"를 삭제한다. 남는 것: ① 탄성 접촉 한계의 정량 규칙과 대리식, ② 패드별 무작위 요인을 포함한 300 nm 공정창과 요인 순위.
3. **계면은 설계 서술로만.** 측벽–라이너 계면을 경계조건으로 명시하고, 밀착 계면이라는 물리적 이유와 실측 판별(미끄럼 대조군 실패)로 접합을 채택했다고 쓴다. 결론이 나지 않은 미끄럼 계면 비교(ST/Leti, Lhostis)는 뺀다. 3.3절은 삭제하고 Ayoub 300 nm 부호는 한계 한 줄로 남긴다.
4. **숫자는 바꾸지 않는다.** 계산 결과는 그대로 두고, 서술 범위와 배치만 바꾼다.

### IV. 4.1 기여 (L95) → 두 개
> **4.1 기여.** 본 연구가 선행연구에 더한 것은 두 가지다. ① **탄성 접촉 한계의 정량 규칙.** (기존 ① 그대로) ② **요인 순위와 판정의 안정성.** 측벽이 접합된 공정에서 공정창을 가장 크게 움직이는 것은 지배 기구와 열예산·표면·라이너이고, recess 산포와 결정방위 같은 패드별 무작위 요인은 수율의 하위 꼬리를 정한다. Ayoub[4]가 방위의 탄성 차이로 recess 사양을 제안한 것과 달리, 접합 패드에서 방위의 탄성 효과는 5 %로 작고(154런 대리모델) 꼬리는 확산 쪽(<111>)에서 생긴다. (이하 기존 ③ 끝 두 문장 그대로)

### IV. 4.2 한계 (L98) — (5)를 범위 문단으로 교체

(v5.1, 사용자 결정 2026-10-16: 미끄럼 계면 분석 — ST/Leti 4관측 비교, Lhostis 두께 효과, 미끄럼 방위 38 %/[111], 높이합 2/4 — 은 결론이 나지 않은 문헌 의존 비교이므로 논문에서 뺀다. 계면은 "모델 설계에서 측벽–라이너 경계조건을 명시적으로 두고, 물리적으로 타당하고 실측이 지지하는 접합을 채택했다"는 방법 서술로만 남긴다. 저장소 기록은 그대로 둔다.)

## 3. 효과

- 기여 문장이 짧아지고 메시지가 "탄성 한계 0.7 µm + 300 nm 공정창(꼬리는 <111>)" 두 줄로 정리된다.
- 서면 4쪽판에서 3.3절(약 10줄)과 서론 한 문장, 2.4 한 문장이 빠져 Fig. 3 또는 Table 2를 살릴 공간이 생긴다.
- 계면은 "경계조건을 명시하고 실측으로 판별해 접합을 채택했다"는 설계 서술 하나로 정리된다. 미결 비교는 본문에 없다.

## 4. 남겨 둔 위험

- 접합 4/4는 기존 기록 재분석(탐색)이다. "검증"이 아니라 "일치"로 쓴다.
- 접합 채택의 근거는 "물리적으로 당연함"이 아니라 **밀착 계면이라는 물리적 이유 + 미끄럼 대조군이 실측을 1.7–3.5배 과대예측한 판별 결과** 두 가지로 쓴다. 실제 계면은 완전 접합과 무마찰 사이 어딘가이므로, 접합은 "실측이 지지하는 근사"다.
- Ayoub 300 nm 부호 불일치는 Table 1·서론에 Ayoub이 나오므로 한계 한 줄로는 남긴다(설명 가설 없이).
